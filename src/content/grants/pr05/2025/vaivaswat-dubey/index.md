This project designs and implements a visual regression testing suite for [Processing](https://processing.org/), inspired by the visual testing suite for [p5.js](https://p5js.org/). The system focuses on comparing the visual output of code sketches, making it easier for contributors to detect regressions, validate changes, and contribute with confidence. The testing approach accounts for differences across platforms and renderer configurations where applicable, and is easy to run both locally and in CI environments, so the community can help test across diverse setups.

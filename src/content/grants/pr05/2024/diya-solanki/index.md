This project focused on developing an official Visual Studio Code (VSCode) extension for Processing, building on the initial Language Server Protocol (LSP) integration in releases 4.1 and 4.3 of Processing. The extension complements the Processing Development Environment (PDE), providing a more feature-rich alternative thanks to the built-in capabilities of VSCode.

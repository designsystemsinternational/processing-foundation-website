### **Develop Shader Learning Examples for p5.strands**

Translate existing GLSL shader examples into p5.strands to demonstrate how creators can manipulate video imagery and adjust the vertices of 3D shapes. These examples show learners how to build filter effects, distort geometry, and animate models using syntax that feels familiar to p5.js users. By making advanced GPU techniques easier to explore, the project supports learning and experimentation with the new p5.strands graphics pipeline. [View the filter shader](https://beta.p5js.org/examples/3D-Filter-Shader-p5strands/), [position-adjustment example](https://beta.p5js.org/examples/3D-Adjusting-Positions-With-A-Shader-p5strands/), and [a shader as a texture](https://beta.p5js.org/examples/Advanced-Canvas-Rendering-Shader-As-A-Texture-p5strands/).

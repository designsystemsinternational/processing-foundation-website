### **Develop a Beginner-Friendly Instancing API for p5.strands**

Create an accessible instancing API that allows p5.js users to draw hundreds or thousands of copies of a shape with a single line of code. Built for the new p5.strands graphics pipeline, the feature improves rendering performance across WebGL and WebGPU while shielding creators from unnecessary technical complexity. This project also includes research into accessibility tooling that could help creators identify potentially unsafe flashing in their sketches and follow WCAG 2.3.2 guidelines. Together, this work makes powerful graphics techniques more approachable while supporting safer and more accessible creative coding experiences. [Read about instancing](https://medium.com/processing-foundation/drawing-a-forest-in-one-line-a-preview-of-instancing-in-p5-strands-a2e93f9c9e04) and [view the accessibility research](https://github.com/processing/p5.js/issues/7841).

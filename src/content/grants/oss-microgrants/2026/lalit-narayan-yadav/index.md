### **Build a Beginner-Friendly Color API for p5.strands**

Extend p5.strands so creators can use familiar p5.js functions such as color(), lerpColor(), and color-channel accessors directly inside shader callbacks. The API supports approachable inputs including hex codes, CSS color names, and rgb() or rgba() strings, reducing the need to construct normalized color vectors manually. This project makes shader programming more intuitive and consistent with the rest of p5.js, allowing beginners to focus on visual experimentation rather than low-level graphics conventions. [View the pull request](https://github.com/processing/p5.js/pull/8822).

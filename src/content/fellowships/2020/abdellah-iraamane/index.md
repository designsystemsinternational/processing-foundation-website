Using creative coding, through Processing software, Abdellah aimed to teach code and languages to children and educators in the remote villages of rural Southern Morocco. He addressed the challenge of the lack of qualified IT educators in rural areas, and aimed to make learning code for first-timers more engaging and enjoyable. Read Abdellah’s article about his project [here](https://medium.com/processing-foundation/teaching-processing-in-arabic-a2461be96168).

For two years I’ve been developing [P5LIVE](https://teddavis.org/p5live/), a p5.js coding environment designed for VJ, live coding, remote collaboration, and teaching. The README thoroughly documents all unique features, but can easily be overwhelming and lacks demonstrative examples. Through this Fellowship, walkthroughs for all current and upcoming Classroom features were produced as a video tutorial series. You can read [about the project in detail here](https://medium.com/processing-foundation/p5live-walking-through-a-collaborative-p5-js-environment-for-live-coding-bc39d95908c6).

# Spacing

Spacing tokens defined in `src/styles/variables.css`. 

Values use `fluid()`
(via `postcss-fluid`) and scale between the min/max viewport widths set in
`postcss.config.js` — bar widths below reflect the live computed size.

## Scale

The base size scale, used to build everything else. 

<div>
  {Object.entries(spaceTokens.scale).map(([name, value]) => (
    <SpacingRow key={name} name={name} value={value} />
  ))}
</div>

## Semantic

Named spacings for specific layout purposes (column gaps, section gaps,
etc).

<div>
  {Object.entries(spaceTokens.semantic).map(([name, value]) => (
    <SpacingRow key={name} name={name} value={value} />
  ))}
</div>

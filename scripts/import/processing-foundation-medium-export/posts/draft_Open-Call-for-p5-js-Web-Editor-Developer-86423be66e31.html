Open Call for p5.js Web Editor Developer

The Processing Foundation is hiring a part-time open source developer in support of the p5.js Web Editor for 3–6 months.

To apply, click here. Deadline: Wednesday, March 27, 2019.

The Processing Foundation’s mission is to promote software literacy within the visual arts, and visual literacy within technology-related fields — and to make these fields accessible to diverse communities. The developer will implement new features for the p5.js Web Editor, one of the many open source projects maintained by the Processing Foundation, and collaborate closely with the current lead maintainer of the project.

The p5.js Web Editor was started three years ago by Cassie Tarakajian as a platform to create, edit, and share p5.js sketches online without needing to download or configure any software. Since then, over 430,000 sketches have been created on the platform, and it is being used in middle school, high school, and university curricula around the world.

The developer will work with project lead Cassie on the following new features for the web editor:

  • API authentication and access to the editor
  • Improved sketch management by allowing users to create collections of sketches

Responsibilities also include:

  • Regular check-in meetings
  • Documentation of new features and contributing guidelines for future developers.
  • Regular updates on Github of progress

The ideal candidate has the following:

  • 1+ years of full-stack web development experience
  • Familiarity working with JavaScript, including modern additions
  • Familiarity working with a web server framework, such as Express, Django, or Rails
  • Experience working with a front-end framework, such as Vue, React, or Backbone

The following experience is a plus, but not required:

  • Working remotely
  • Working on open source
  • Familiarity with Processing Foundation tools, such as p5.js or Processing

This position is a contract position for a term of three months (with the possibility to renew for an additional three). The expectation is 16 hours per week, with a base pay of $3,200 per month. Our team has members based in New York, Boston, Los Angeles, San Francisco Bay Area, and Berlin, and we work together online, and in person when we can. The developer will work remotely, and can be based anywhere, though will need to overlap with New York/EST working hours.

The Processing Foundation provides equal employment opportunities to all without regard to race, ethnicity, color, religion, gender identity, sexual orientation, national origin, age, disability, or genetics. Candidates from groups generally underrepresented in the arts or tech fields are especially encouraged to apply.

To apply, please fill out the following form by Wednesday, March 27, 2019. Start date is flexible, aiming for Monday, April 15, 2019.
